# Statistical Analysis of Student Academic Performance

## Objective

This project investigates the influence of gender and parental educational attainment on student academic performance in Mathematics and Language subjects.

## Research Questions

1. Does gender significantly influence Mathematics performance?
2. Does gender significantly influence Language performance?
3. Does parental educational attainment significantly influence Mathematics performance?
4. Does parental educational attainment significantly influence Language performance?

## Methods

- Descriptive Statistics
- Independent Samples t-Test
- Cohen's d Effect Size
- One-Way ANOVA
- Tukey HSD Post-hoc Analysis
- Data Visualization

## Dataset

972 student performance records.

Variables:

- student_id
- gender
- parental level of education
- subject
- score
